# Potterdle Unlimited

A personal Wordle-style Harry Potter character-guessing game with unlimited rounds. Built from the Cosmeredle Unlimited engine.

## Play

Open `index.html` in a browser. There's no build step and no server.

## Columns

Character · House · First book (▲/▼ if the answer appears later or earlier) · Blood status · Affiliation · Family

## Updating the character list

Edit `tools/characters.source.json` (the format is described at the top of `tools/build_data.py`), then run:

```sh
python3 tools/build_data.py
```

Harry Potter characters and settings belong to their owners. This is a fan project for personal use only.

## Game modes

Besides Classic, there are five clue modes (tabs under the header): **Quote**, **Spell**, **Potion**, **Description** and **Location**. Hints unlock after a set number of wrong guesses. Their data lives in `modes-data.js`, generated by `python3 tools/build_modes.py` from:

- `tools/data/spells.json`, `tools/data/potions.json` from [the-harry-potter-database](https://github.com/theDavidBarton/the-harry-potter-database) (MIT, license in `tools/data/`)
- `tools/quotes.source.json`, `tools/descriptions.source.json`, `tools/locations.source.json` (hand-written)
